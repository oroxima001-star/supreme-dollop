# Ordenação Web - Quick Sort

## Sobre o Projeto
Este projeto apresenta o algoritmo Quick Sort funcionando diretamente no navegador utilizando HTML, CSS e JavaScript.

## Funcionalidades
- Gerar vetor aleatório
- Ordenar vetor
- Visualização gráfica
- Interface moderna

## Complexidade
- Melhor caso: O(n log n)
- Caso médio: O(n log n)
- Pior caso: O(n²)
